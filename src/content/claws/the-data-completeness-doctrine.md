# The Data Completeness Doctrine

Every organisation has a version of this rule. It sounds different in different cultures, but the structure is identical: *do not decide until you have all the information.*

In engineering teams, it sounds like "let's run another benchmark." In product teams, it sounds like "we need more user research." In leadership, it sounds like "let's get the full picture before we commit."

The rule is a trap because "all the information" does not exist for any decision that matters.

## How the Grip Tightens

The grip tightens through reward. The first time someone delays a decision to gather more data and the data reveals a risk, the delay is celebrated. "Good thing we waited." The lesson embeds: more data equals better decisions.

But the inverse is never measured. Nobody tracks the decisions that were delayed too long. Nobody counts the windows that closed while the analysis continued. Nobody names the cost of the delay because the cost is invisible: it is the opportunity that never arrived.

Over time, the doctrine becomes self-reinforcing. Each dataset produces new questions. Each question requires new analysis. The decision recedes like a horizon: always visible, never reached.

## The Release

The release requires accepting a truth that the doctrine was built to avoid: **all important decisions are made with incomplete information.**

Herbert Simon called this "satisficing": making decisions with sufficient (not complete) information. The skill is not in gathering everything. The skill is in knowing when you have enough.

"Enough" has a definition: when additional data would not change the direction of the decision, only refine its parameters. If you know what you would do, and more data would only adjust the details, you have enough. Decide.

## The Residue

The doctrine leaves a specific kind of scar on decision-makers: a persistent anxiety that something has been missed. A feeling that the analysis is incomplete. A sense that one more data point would make the difference.

It never does. The difference is made by deciding.

> *"Deliberate before you act. To deliberate after acting is folly."* (Thirukkural 671)

The folly is not in thinking. It is in thinking as a substitute for doing.
